# FMC

We’re curious about how CMF devices work and what else we can do with them. We build open-source tools and share what we learn so others can build on it.

Our website is [fmc.tools](https://fmc.tools).

## Projects

| Project | Description |
| --- | --- |
| [FMC](https://github.com/fmctools/fmc) | A watch-face editor and [community gallery](https://fmc.tools/) for Watch Pro 2 and Watch 3 Pro, with [apps](https://fmc.tools/apps) and [firmware downloads](https://fmc.tools/firmware). |
| [CMF Watch Utils](https://github.com/fmctools/cmf-watch-utils) | Firmware and Bluetooth tools, [technical documentation](https://cmf.arnv.dev/), and [QEMU emulators](https://cmf.arnv.dev/emulator/) for Watch Pro 2 and Watch 3 Pro. |
| [CMF Watch SDK](https://github.com/fmctools/cmf-watch-sdk) | A loader and [Rust SDK](https://github.com/fmctools/cmf-watch-sdk/blob/HEAD/docs/app-guide.md) for installable Watch Pro 2 apps. |
| [Community apps](https://github.com/fmctools/apps) | Installable Watch Pro 2 apps published to the [FMC app store](https://fmc.tools/apps). |
| [Bad Apple firmware](https://github.com/fmctools/firmware-wp2-badapple) | Custom firmware built from Zephyr source that [plays Bad Apple on the Watch Pro 2](https://youtu.be/npPfNpdD0O8). |

## Community

We welcome new contributors across our projects. Code, design, device testing, and documentation all have a place here. We share findings and discuss ideas on [FMC Community on Discord](https://discord.gg/KnAFruMabJ) and [r/CMFWatchMods](https://www.reddit.com/r/CMFWatchMods/).

*We’re independent of CMF and Nothing.*
