# CMF Tech Community

We’re curious about how CMF devices work and what else we can do with them. We build open-source tools and share what we learn so others can build on it.

## Projects

| Project | Description |
| --- | --- |
| [FMC](https://github.com/cmf-tech-community/fmc) | A watch face editor and [community gallery](https://fmc.freethinkel.dev/) for the Watch Pro 2 and Watch 3 Pro. |
| [CMF Watch Utils](https://github.com/cmf-tech-community/cmf-watch-utils) | Firmware and Bluetooth tools for the Watch Pro 2, with [technical documentation](https://cmf.arnv.dev/) and a [browser emulator](https://cmf.arnv.dev/emulator/watch-pro-2/) built on QEMU. |
| [WP2 Apps](https://github.com/cmf-tech-community/wp2-apps) | A loader and [Rust SDK](https://github.com/cmf-tech-community/wp2-apps/blob/HEAD/docs/app-guide.md) for installable Watch Pro 2 apps. |
| [Bad Apple firmware](https://github.com/cmf-tech-community/firmware-wp2-badapple) | Custom firmware built from Zephyr source that [plays Bad Apple on the Watch Pro 2](https://youtu.be/npPfNpdD0O8). |

## Community

We welcome new contributors across our projects. Code, design, device testing, and documentation all have a place here. We share findings and discuss ideas on [Discord](https://discord.gg/KnAFruMabJ).

*We’re independent of CMF and Nothing.*
